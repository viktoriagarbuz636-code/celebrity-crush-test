# Celebrity Crush Test 💗 (Версия для PowerPoint-пати)

Развлекательный русскоязычный веб-тест для вечеринки с подругами, готовый к публикации на **GitHub Pages** с общей базой результатов в **Supabase** (и встроенным локальным демо-режимом для быстрого предпросмотра без настройки БД).

## Состав проекта (все 7 файлов в папке)

- `index.html` — страница теста (стартовый экран с вводом ника и фильтром категорий, 10 вопросов, карточка результата с разбором типажа и близкими совпадениями);
- `results.html` — общая доска результатов для показа на экране/проекторе (со статистикой вечеринки, кнопкой копирования ссылки и автоматическим Live-обновлением);
- `app.js` — каталог из **89 кандидатов** (включая **50 российских знаменитостей и спортсменов** — более 56% базы, а также зарубежных футболистов, голливудских актёров, персонажей и 3 секретных результата), логика теста и интеграция с Supabase;
- `styles.css` — адаптивное оформление для смартфонов, ноутбуков и проектора;
- `supabase.sql` — идемпотентный SQL-скрипт для создания таблицы `public.quiz_results`, функции проверки ID, индексов, колонночных прав `INSERT` и политик Row Level Security (RLS);
- `.nojekyll` — технический пустой файл, отключающий пересборку Jekyll на GitHub Pages;
- `README.md` — эта инструкция по настройке и запуску.

## Шаг 1. Настройка облачной базы Supabase (чтобы доска была общей для всех телефонов)

> **Примечание:** если открыть сайт до настройки Supabase, он автоматически работает в **Демо-режиме** (результаты сохраняются локально в текущем браузере). Чтобы результаты всех подруг со смартфонов собирались на одном общем экране, подключи бесплатный проект Supabase:

1. Зарегистрируйся или войди на [supabase.com](https://supabase.com/) и нажми **New project**.
2. Укажи название проекта (например, `celebrity-crush-test`), задай любой надёжный пароль базы данных, выбери ближайший регион и нажми **Create new project**.
3. Подожди 1–2 минуты, пока проект развернётся.
4. В левом меню открой **SQL Editor → New query**.
5. Скопируй **всё содержимое** файла `supabase.sql`, вставь в редактор и нажми **Run** (или `Ctrl + Enter`). Внизу должно появиться сообщение `Success. No rows returned`.
6. Перейди в **Project Settings (иконка шестерёнки внизу слева) → API** (или нажми кнопку **Connect** в верхней панели):
   - Скопируй **Project URL** (вида `https://xxxxxxxxxxxx.supabase.co`).
   - Скопируй публичный ключ: **Publishable key** (`sb_publishable_...`) или **anon public** (`eyJ...`).
7. Открой файл `app.js` и замени значения в первых двух константах:

```js
const SUPABASE_URL = "https://ТВОЙ_ID_ПРОЕКТА.supabase.co";
const SUPABASE_PUBLISHABLE_KEY = "sb_publishable_ТВОЙ_КЛЮЧ_ИЛИ_eyJ...";
```

> ⚠️ **Важно по безопасности:** вставляй в `app.js` только публичный ключ (`Publishable key` / `anon public`). Никогда не вставляй `service_role` или `sb_secret_...` в клиентский код (в `app.js` встроена автоматическая защита, которая предупредит, если случайно вставить секретный ключ).

## Шаг 2. Публикация на GitHub Pages

1. Войди в свой аккаунт на [github.com](https://github.com/) и нажми **New repository** (`+` в правом верхнем углу).
2. Назови репозиторий, например `celebrity-crush-test`.
3. Выбери тип **Public** (для бесплатного GitHub Pages репозиторий должен быть публичным) и нажми **Create repository**.
4. Нажми **uploading an existing file** (или кнопку **Add file → Upload files**).
5. Перетащи в окно браузера файлы из этой папки: `index.html`, `results.html`, `app.js`, `styles.css`, `.nojekyll`, `README.md` (файл `supabase.sql` загружать необязательно, но можно оставить для резервной копии).
6. Внизу страницы нажми зелёную кнопку **Commit changes**.
7. Перейди во вкладку **Settings** репозитория → в левом меню выбери **Pages**.
8. В блоке **Build and deployment** в выпадающем списке **Source** оставь **Deploy from a branch**.
9. В списке **Branch** выбери `main` и папку `/ (root)`, затем нажми **Save**.
10. Подожди 1–2 минуты и обнови страницу `Settings → Pages`. Сверху появится плашка:
    `Your site is live at https://<твой-логин>.github.io/celebrity-crush-test/`

## Шаг 3. Как провести интерактив на PowerPoint-пати

1. На ноутбуке, подключённом к телевизору или проектору, открой страницу результатов:
   `https://<твой-логин>.github.io/celebrity-crush-test/results.html`
2. Нажми кнопку **«📱 Ссылка для подруг»** на панели управления, скопируй ссылку на тест (`.../index.html`) и отправь её в ваш общий чат.
3. Подруги открывают ссылку с телефонов, по желанию сразу вводят своё имя на стартовом экране (галочка автопубликации включена по умолчанию) и отвечают на 10 вопросов.
4. Как только участница доходит до 10-го вопроса, её результат автоматически прилетает на общую доску на большом экране (благодаря Live-обновлению), а статистика вечеринки («Участниц на доске», «Главный вайб вечеринки», «Популярный краш») пересчитывается на лету!
5. Если перед самой вечеринкой ты тестировала сайт и хочешь очистить тестовые записи из облачной базы Supabase, открой в Supabase раздел **Table Editor → `quiz_results`**, выдели тестовые строки и нажми **Delete rows**.
